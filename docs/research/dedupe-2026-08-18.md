# Phase 0 dedupe record, 2026-08-18

Every `NEEDS-PRIMARY` claim in this corpus, classified against what the repository already
establishes. This is the artifact Phase 0 of `docs/plans/2026-08-18-single-source-to-primary.md`
asks for.

**Read the method note before using this file.** A keyword pass was built for this job first, run,
and rejected: five of its already-in-repo verdicts flipped when the hits were read in context. The
standing rule in `CLAUDE.md` is that a null result is a claim about the query. The corollary this
pass establishes is that **a hit is not confirmation either**. Everything below was read in
context, not matched.

### The gap: B5, B6, B7, B8 are `CACHE`, not `OPEN`

CNBC listed four New Mexico age-assurance remedies. The ledger does **not** carry them: claim 40
summarises Age Assurance at heading level only, and the ledger's own coverage note lists Age
Assurance among the "sections of the order not yet distilled".

But the order is **already cached** in this repository, and the remedies are in it verbatim. All
four check out against the primary, at paragraph 142:

| Claim | Status against the cached order |
| --- | --- |
| B5, age assurance improved using AI | Confirmed. The order requires continuing to improve age assurance models and tools, including using artificial intelligence to enhance heuristics |
| B6, under-13 prediction model within two years | Confirmed, and CNBC dropped the qualifier. The order says "attempting to develop", on "reasonable best efforts", and expressly "in light of COPPA limitations" |
| B7, easier reporting of underage users | Confirmed. Item (g) requires reducing the number of steps and the information required |
| B8, school reporting portal | Confirmed, and it is broader than CNBC said: the portal covers suspected under-13 accounts "across any social media platform", not only Meta's |

**And the framing all four sources missed.** Paragraph 142 records that this relief is
**Meta's own proposal**, which the court adopted while calling it "far from ideal or sufficient",
because better options were unavailable to it for want of jurisdiction over other parties. That is
the same separation-of-powers limit that produced the refusal at paragraphs 160 to 166, showing up
on the granted side of the order too.

This is the single most valuable finding of the dedupe: **a court described the child-safety
remedies it did order as inadequate, and said so on the record.** For a site arguing that
litigation cannot fit the brake, a judge conceding the point while granting relief is stronger
evidence than the refusal alone.

**Action:** Phase 4 should distil the Age Assurance section into the New Mexico ledger. It costs
one reading pass over a file already in the repository and closes the ledger's own declared gap.
