2. **February (G22) versus March, which three other sources in this batch give for the LA verdict.** Internally unremarkable, externally a date conflict.
3. **$567m (G20) and $942m (G21) in adjacent sentences**, correctly explained as two phases, but the article's own related-link furniture rounds the same total to $900m. The document disagrees with its own page.
4. **G13 says "if Meta is found liable, damages could be as high as $200bn", which is conditional; G14 then scales it as if settled.**
