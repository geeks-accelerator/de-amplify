# Issue index

Every file in this directory, and nothing else. `npm run check:issues` asserts the match in both
directions, so a row without a file and a file without a row both fail.

**Read [README.md](README.md) before adding one.** The boundary matters more than the format: a
question about the record of one proceeding belongs in that ledger's Tensions section, of which
there are more than sixty, not here.

Sorted by status, unresolved first. The Opened column shows a close date where there is one.

The `Status` cell is checked against each file's own frontmatter, so a row cannot describe a closed
thread as open. It could until 2026-08-20, and did: the two-directional match only ever compared
which files were listed, never what the rows said about them.
